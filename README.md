# FAREVER PRO - Advanced Modding Dashboard

Dashboard avanzata ottimizzata per Windows. Sviluppata per Zet4x600.

## 🚀 Guida all'installazione su PC Windows

1.  **Requisiti**: Installa [Node.js](https://nodejs.org/) (versione LTS consigliata).
2.  **Scarica il progetto**:
    ```bash
    git clone https://github.com/Zet4x600/farever-pro.git
    cd farever-pro
    ```
3.  **Installa le dipendenze**:
    ```bash
    npm install
    ```
4.  **Avvia l'applicazione**:
    ```bash
    npm run dev
    ```

## 🛠 Comandi Sviluppo
- `npm run dev`: Avvia il server sulla porta 9005.
- `npm run electron:dev`: Avvia l'interfaccia Electron (richiede server attivo).
